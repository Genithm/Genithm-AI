# Science V9 — production scientific results explorer

Scope: the **authenticated production scientific job page**. The explorer is not the earlier Codespaces preview. It shows the actual artifacts generated by the scientific worker for real authorized queued jobs.

## Data and security architecture

`RLS-scoped signed-in session → scientific_jobs authorization → canonical tenant/object identity → private analysis-results storage → exact recorded byte count and SHA-256 verification → strict bounded parsing → minimal JSON projection → client visualization`

The server-only `/dashboard/scientific-jobs/[id]/explore` GET route reuses the V8 trusted `scientificResultDescriptor` and `verifiedScientificResultBytes` rules; it does not use a service-role key, signed download URL, or user-supplied bucket/path. Its result includes a SHA-256 verification indicator only after verifying the **actual downloaded bytes**. A mismatched or malformed result is fail-closed (HTTP 409 without biological content); unauthenticated, unauthorized or missing jobs get 401/404. Responses have private no-store headers.

The optional query parameters `offset` and `row` are bounded nonnegative integers for scrolling, never arbitrary storage paths or SQL parameters. Raw artifacts remain private. The response is an intentionally bounded derived view. Storage objects up to the V8 25 MiB cap are read and checked server-side, so exploring a giant alignment has a meaningful storage/network cost; this milestone adds no caching or compute billing.

## Supported scientific views

| Production result type | What the explorer renders | Important scientific caveat |
| --- | --- | --- |
| Pairwise global/local alignment | Windowed 96-column A/B rows, concordance, matches, mismatches and gap counts | Alignment alone does not prove functional similarity |
| MAFFT multiple sequence alignment | Windowed records (12 at a time), aligned residue content and 128-or-fewer sampled column conservation bars | Bars are non-gap majority fraction, **not** conservation significance or bootstrap support |
| FastTree phylogeny | A branch-length-based SVG tree with leaf labels and supported internal node tooltips | Diagram root is display-only; no biological rooting claim |
| Sequence insights | Bounded ORF coordinates, IUPAC motif hits, six-frame peptide excerpts or reverse-complement excerpt | Coordinates are 1-based inclusive; no experimental or clinical annotation |
| Protein properties | Counts per amino acid, molecular weight, aromaticity, GRAVY, estimated charge and pI | Model estimates are not experimental measurements |

The standalone canonical raw-result download is unchanged and remains available for full evidence. The new explorer only displays portions of sequence data: first 48 evidence records, 96-base alignment windows and sampled MSA summary bars. Users can page MSA columns and the visible record subset. The interface is responsive, keyboard-accessible and uses semantic text with SVG tree labels.

## Validation and rollout

```sh
cd apps/web
npm ci
node --experimental-strip-types --test tests/scientific-explorer.test.mjs
node --experimental-strip-types --test tests/scientific-result-integrity.test.mjs
npm run typecheck
npm run build
```

The V9 tests cover canonical/alphabet/dimension rejection, 12-record/96-column pagination, real sampled conservation, exact Newick leaves and branch/support limits, protein summaries and sequence analytics, malformed/forged artifacts and missing evidence. Existing CI continues to run web, worker, security and Cloudflare checks as dictated by changed paths.

**No live Supabase SQL changes, no Oracle deployment, no AI model permissions, and no new scientific computation algorithms.** Worker-side independent scientific evidence validation remains authoritative for biological calculations; this feature projects validated artifacts for a researcher-facing interface.
